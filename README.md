# AI-Knowledge-Pipeline

AI 知识整理系统。第一阶段采用资料转换、AI 辅助起草和人工审核，验证可追溯笔记与审核负担。

用户于 2026-10-12 明确选择此项目名称并授权建立本地仓库，取代此前“本阶段不建独立仓库”的安排。当前仓库用于计划、规则和后续工具；现有 Obsidian Vault 不迁移到这里。

当前工具行为与边界见 [本地整理工具使用](docs/本地整理工具使用.md)、`docs/` 中的验收记录及 [项目规则](AGENTS.md)。早期规划文档未包含在当前仓库中；文档中的命令不作为自动执行指令。

已完成手动本地整理工具。工具只转换指定文件并新建来源草稿，不调用模型、不自动发布或导入。仓库仅保存规则、工具源码、测试和使用文档；原始资料、转换全文及运行数据不进入 Git。
