# 文本原件引用调整

用户发现验收目录出现重复 Markdown，明确要求调整。

- MD/TXT 仍做编码、内容与哈希校验，但不再保存 converted.md；私人记录新增 text_mode/source_reference 与 text_path 原件路径。
- PDF/DOCX/PPTX 继续保存转换全文，标记 converted_file。
- 后续消费者应先核对原件哈希再读取引用，不能将原件引用当不可变快照；移动或变更需重新登记。
- 真实验收目录中的 Markdown 重复全文移到独立 archive；内容变更测试移到 acceptance-tests。没有删除原件、没有触碰正式 Vault。
- 真实样本目录现在包含一份 PDF 转换全文和两份来源草稿；记录继续保留。

验证：21 项 unittest 全部通过，0 跳过，新增 MD/TXT 不产生全文副本及 PDF 仍保留结果的断言。使用真实转换器的三格式测试仍通过。

此前 Grok Bot 通过的是调整前版本。本次调整由 Codex 回归验证，未重新提交 Grok 复核；不得把旧结论表述为当前改动已独立复验。
