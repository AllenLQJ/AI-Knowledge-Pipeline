# 本地整理工具使用

本工具经 Allen 明确授权开发，扩展原第一阶段的手工转换步骤；仍由人工触发单个文件，不扫描整个 Vault，不调用起草模型，不发布、不导入面试助手。来源草稿中没有原文正文，转换全文仅放 Vault 和 Git 仓库之外的私人目录。

## 环境

本版本仅支持 macOS/Linux 的 fcntl 文件锁，不支持 Windows 执行。Mac 使用 Python 3.12，独立环境位于 `/Users/allen/.local/share/ai-knowledge-pipeline/venv`。MD/TXT 仅需标准库；Office/PDF 需 `markitdown[pdf,docx,pptx]`，实际验证版本见验收记录及 requirements-conversion.txt。插件关闭，转换使用 convert_local；没有配置 LLM 或云端服务。

在项目根运行，先只读检查：

```sh
/Users/allen/.local/share/ai-knowledge-pipeline/venv/bin/python -m knowledge_pipeline.cli inspect --source /资料根/样本.md --source-root /资料根
```

确认原件和 Vault 备份、资料许可及相对路径可写入草稿后再准备：

```sh
/Users/allen/.local/share/ai-knowledge-pipeline/venv/bin/python -m knowledge_pipeline.cli prepare \
  --source /资料根/样本.md \
  --source-root /资料根 \
  --vault '/Volumes/T7 Shield/Mac/Projects/My_Knowledge_Base' \
  --output /私人目录/转换结果 \
  --root-id learning-materials \
  --permission-id permit-001 \
  --allow-source-metadata
```

示例路径是占位符，不应直接执行。许可编号对应 Vault 外的人工记录，工具只验证编号格式，不能判断授权真实性。相对路径也可能敏感，不应自动批准该参数。

输出目录必须在 Vault 和所有 Git 仓库之外，不能与 Vault 互为父目录。输入与输出路径链拒绝软链接；macOS `/tmp` 等系统别名请使用解析后的真实路径。该检查是工具层约束，不是文件系统沙箱，不能对抗恶意并发替换路径。

## 行为

- 只接受单个 MD/TXT/PDF/DOCX/PPTX，源文件最多 10 MB，转换文字最多 20 MB。
- 文本要求 UTF-8；Office/PDF 子进程超时 90 秒。页码、表格、公式需对照原件，不自动宣称可靠。
- MD/TXT 只校验并引用原件，不创建 converted.md；record.json 的 text_mode 为 source_reference，text_path 指向原件。后续读取前必须再次核对 sha256，原件移动或变化时重新登记，不能把引用当不可变快照。
- PDF/DOCX/PPTX 保存 converted.md；text_mode 为 converted_file，text_path 指向私人转换结果。source_path 始终指向原件。历史记录缺少这些字段时不得猜测，应人工核查后重新登记。
- 内容修改测试使用独立测试目录，不混入真实资料验收结果。
- 查重仅读取指定 AI 学习目录的来源索引和来源草稿；同哈希跳过。同哈希多记录停止，同路径不同内容提示人工关联版本。
- 使用本机文件锁串行准备，来源草稿独占创建，已有文件不覆盖。
- 转换失败、源文件变化、写入阶段失败在私人输出目录写 failed 记录，不生成空概念或来源，不修改旧记录。磁盘故障也可能使失败记录无法保存，此时明确报告。人工可依据错误使用来源模板记录失败；已有 state: failed 的同哈希来源会停止，必须人工处理该记录后再重试，不会误报成功跳过。
- 转换中源文件变化停止。私人转换结果已存在但无草稿时可能是中断，停止并要求人工核查；不自动清理、重试或复用部分结果。重试方法：确认来源草稿与正式索引均无对应有效记录后，在私人目录人工将 `<sha256>/` 改名为带日期的中断备份，再运行相同命令；不要删除无法确认的记录。人工删除来源草稿后也按此流程处理，不能把删除草稿当自动恢复指令。
- 查重支持来源记录的 BOM、CRLF 和标量后的注释；解析失败、哈希缺失或重复字段时停止并给出文件路径。本工具仅支持约定的顶层标量形式，不是通用 YAML 解析器。
- `90-资料来源索引/` 和 `_staging/来源草稿/` 仅放来源记录，不放 README、模板或普通概念笔记；这些文件缺少有效来源哈希时会使检查安全停止。
- 私人 record.json 保存转换完成意图及最终状态。成功后在 `_staging/来源草稿/` 新建带完整 sha256 标识的来源笔记；不写正式目录。
- 不生成概念内容；后续由获准模型或人工对私人转换结果起草。不得将未获许可原文发送云端。
